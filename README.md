## 1. 프로젝트 소개

**「오늘 뭐 해먹지? : 조리법 레시피 연구소」**는 중학교 기술·가정 교과 [가족의 식사 조리] 단원을 위해 개발된 실습형 교육 웹앱입니다.

학생들은 요리 연구원이 되어, 랜덤으로 주어지는 **재료 + 8대 가열조리/생조리법 + 요리 미션 카드**를 바탕으로 모둠별 창의적인 신메뉴를 개발하고, 식사 조리 순서(계량·다듬기·씻기·썰기·가열하기·맛내기·상차림·뒷정리)를 계획하며, 가공식품 속 **식품 첨가물(보존료, 발색제, 향미증진제 등)을 줄이는 건강한 조리 수칙**을 반영합니다. 완성된 레시피는 **AI Food Designer**를 통해 사실적인 완성 음식 사진으로 시각화하고 검증한 후 교실 전자칠판으로 함께 공유합니다.

## 2. 주요 교육 흐름

```
[시작] 모둠 이름 및 연구원 등록
   ↓
[STEP 1] 🎴 3종 랜덤 카드 뽑기 (재료 + 조리법 + 미션) & 다시 뽑기(1/1)
   ↓
[STEP 2] 📝 레시피 연구소 (메뉴명, 조리시간, 조리도구, 다단계 조리 순서, 체크리스트, 조리법 선택 이유)
   ↓
[STEP 3] 🔍 식품 첨가물 탐정 (가공식품 탐색, 대표 첨가물 분석, 데치기/국물버리기/구워먹기 등 안심 수칙 적용)
   ↓
[STEP 4] 🎨 AI Food Designer (학생 레시피 최우선 시각화, 조리 질감 표현, AI 이미지 검증 체크리스트 및 수정 재요청)
   ↓
[STEP 5] 🍽️ 메뉴 완성 (신메뉴 메뉴판 발행, 인쇄/PDF, 요약 복사, 교실 전체 메뉴판 등록)
   ↓
[공유] 📺 전자칠판 전체 모둠 메뉴판 & 발표 모드
```

## 3. 교과 학습 내용 반영

### 3-1. 조리(Cooking)의 의의
- 식품을 재료로 먹을 수 있는 음식을 만드는 과정
- 영양적 가치 향상, 기호적 가치 향상, 안전성 증대

### 3-2. 조리 방법 (열전달 매체에 따른 분류)
1. **생조리**: 가열하지 않고 손질·양념 (샐러드, 생채, 회, 장아찌)
2. **끓이기(삶기)**: 물에 넣고 가열하여 익힘 (된장찌개, 수육, 감자 삶기)
3. **데치기**: 끓는 물에서 짧은 시간에 살짝 익힘 (시금치 나물, 브로콜리 숙회, 소시지 데치기)
4. **찌기**: 물을 가열해 생긴 수증기로 익힘 (고구마 찜, 계란찜, 만두)
5. **조리기**: 양념을 넣고 센 불로 끓이다 약한 불에서 국물이 졸아들 때까지 가열 (감자조림, 두부조림, 고등어조림)
6. **볶기**: 적은 양의 기름을 두르고 센 불에서 짧은 시간 가열 (야채볶음, 어묵볶음, 볶음밥)
7. **부치기**: 적은 양의 기름을 두르고 지지는 방법 (두부부침, 김치전, 감자전)
8. **튀기기**: 많은 양의 끓는 기름 속에서 단시간에 익힘 (치킨, 감자튀김, 탕수육)
9. **굽기**: 프라이팬, 석쇠 직접열이나 오븐의 뜨거운 공기로 익힘 (고등어구이, 토스트, 스테이크)

### 3-3. 식품 첨가물을 적게 먹는 조리 비법
- **햄·소시지·어묵** → 끓는 물에 2~3분 데친다.
- **통조림 (참치 등)** → 국물은 버리고 조리한다.
- **라면** → 면 삶은 물은 버리고, 수프만 따로 끓인 물에 삶은 면을 넣어 다시 끓인다.
- **식빵** → 구워 먹는다.
- **단무지·피클** → 찬물에 5분 이상 담갔다가 먹는다.

## 4. 기술 스택

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion
- **Icons**: Lucide React
- **Backend / Dev**: Node.js, Express, Vite 8, tsx
- **AI Integration**: `@google/genai` (Imagen 3 / Gemini Image Generation) + Client Photorealistic Studio Plating Canvas Fallback
- **Persistence**: `localStorage` (새로고침 시 모둠 진행 상황 및 전체 모둠 데이터 안전 보존)

## 5. 설치 및 실행 방법

### 요구 사항
- Node.js 18.0.0 이상
- npm 9.0.0 이상

### 설치
```bash
npm install
```

### 환경 변수 설정 (.env)
```bash
# 선택 사항: Gemini Imagen AI 음식 사진 생성을 위한 API 키
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```
*(API 키가 설정되지 않아도 내장된 고화질 푸드 스튜디오 플레이팅 캔버스 렌더러가 작동하여 수업이 끊김 없이 진행됩니다.)*

### 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

### 프로덕션 빌드 & 테스트
```bash
# 빌드
npm run build

# 미리보기
npm run preview
```
